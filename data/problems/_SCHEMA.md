# Problems — `data/problems/<slug>.json`

One `Problem` per file (see `src/content/types.ts`): the ~25 issues common on
a Dutch balcony (slakken, luizen, meeldauw, neusrot, …). `parts` drives the
Diagnose browser's "by plant part" filter; `affects` lists crop slugs.
Treatment is organic-first. `verified` + `sources` as for crops.
